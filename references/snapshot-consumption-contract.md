# Snapshot Consumption Contract

A snapshot is structural evidence, not a design conclusion.

Do not infer design intent, architecture style, code quality, technical debt, refactor necessity, module ownership, or runtime behavior solely from snapshot data.

Use snapshot fields to initialize `onboarding.md` and the `Evidence From Snapshot` section in `design-digest.md`. Do not create `refactor-plan.md` from snapshot alone.

If warnings include `SCOPE_IS_REPO_ROOT` or `LARGE_SCOPE`, suggest Scope Discovery or ask the user to narrow scope.
